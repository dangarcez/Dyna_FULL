Simulador de classificação de problemas

Cole o Raw Response de uma consulta DQL. Cada registro simula o estado atual do problema. A classificação prioriza a causa raiz Smartscape, depois a legada e, se nenhuma delas permitir decidir, usa o nível de impacto como fallback.

1. Dados de entrada

Aceita result.records, records, um array ou um único registro JSON.

Nada é enviado para a internet. Atalho: Ctrl + Enter.
Configurações de roteamento (opcional)

Use os nomes de Assignment Group desejados e exceções por ID de entidade. A classificação principal segue os conjuntos de tipos do JavaScript original.

Valores aceitos: INFRAESTRUTURA, APLICACAO ou TRIAGEM.

Os níveis de impacto indicam efeitos observados, não comprovam a causa raiz. Registros com o mesmo event.id são avaliados separadamente, sem mesclar snapshots.
